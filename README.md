# Carl & Cy — Wedding Day Reminders

Scrapbook-style wedding day reminders website for **Carl & Cy** (November 26, 2026), built with React 19, Vite 8, and Tailwind CSS v4 to match the main wedding website aesthetic.

## Sections
1. **Our Wedding Day** — Welcome note card, polaroid photo with wax seal, and live countdown to November 26, 2026 at 1:00 PM
2. **The Ceremony & The Reception** — Chapel on the Hill & Windsong Tagaytay photo cards, Google Maps links, Waze note (pin Gorio's Restaurant), and interactive route map
3. **A Few Gentle Reminders** — Scrapbook cards with washi tape, floral stickers, and dress code color palette swatches
4. **Your Presence is Our Greatest Gift** — Couple's gratitude note, tap-to-enlarge BPI InstaPay QR code, and sign-off

## Commands
```bash
npm install
npm run dev      # Start local dev server
npm run build    # Build for production
```
